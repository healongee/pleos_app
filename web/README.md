# Pleos shelter private demo

Node.js 20+. Run `npm test`, then `npm start` from `web/`; visit http://127.0.0.1:3000. State and sessions are in memory and disappear on restart. To test two roles, use separate browser profiles. The owner must select the owner of the listed shelter. No real account numbers or personal information: the role picker is **not authentication** and any visitor can impersonate any owner/customer. Never expose this demo publicly (including cloud, port forwarding, or shared LAN); browser cookies and accounts on HTTP are not secure. The only supported binding is loopback.

Customer requests a specific listing/owner → owner sends *fictional* transfer instructions → customer sees them and transfers externally (not simulated or processed) → owner independently checks their bank app and attests receipt → owner requests unlock → server records `MOCK_REQUEST_ONLY` (door remains locked) → owner may close request. Owner attestation is NOT bank verification. Access to requests is scoped to demo browser session or selected owner; this does not protect against an attacker who can choose a role. Restart discards everything. Only one active request per listing. No real booking time, vehicle pairing or notifications: browser polling every 5 seconds is used.

Optional map: set `KAKAO_JS_KEY=<your browser JavaScript key> npm start` locally (see `.env.example` for the variable name; this demo does not automatically load `.env` files). Register only the intended website origins in Kakao Developers JavaScript SDK allowed domains, and remove unused origins. The JavaScript key is **public by design**: `/api/config` returns it to every visitor and the browser sends it to Kakao. Never use a Kakao REST/admin key or other secret here. If a key has already been shared outside its intended audience, rotate it in Kakao Developers and restrict the replacement key's allowed origins. Never commit the real value, put it in screenshots, or deploy this unauthenticated demo to the internet. Without a key, the listing remains usable. The map shows **fictional listing coordinates**; optional 'Use my location' requires explicit browser consent and HTTPS or localhost, and location is not sent to our server. See https://apis.map.kakao.com/web/guide/.

The Android project is a separate, offline, local-only vehicle console mock; web unlock state does not activate a vehicle session. Before real deployment decide: cloud host and HTTPS/domain; verified customer/owner identity and account ownership; encrypted bank details storage/retention and consent; trusted vehicle gateway authorization, device binding and signed unlock acknowledgement; Pleos/OEM SDK availability and controls/park-state restrictions; approved media packages and distribution. No real vehicle, banking or streaming integration is implemented.
